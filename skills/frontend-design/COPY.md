# Interface Copy

Write from the user's side of the screen. Name what people recognize and control, using plain, specific language rather than implementation terms or sales language.

- Give each string one job: labels identify, help text explains, examples demonstrate.
- Name actions by their result: “Save changes,” not “Submit.” Keep that verb consistent through confirmation and error states.
- Prefer active voice, sentence case, short verbs, and a register matched to the audience.
- Make errors state what happened and the next action. Make empty states point toward a useful first action.
- Preserve the interface's vocabulary across navigation, controls, feedback, and documentation.

**Complete when:** every visible string is specific to its context, uses consistent terms, and tells the user what they can understand or do next.
